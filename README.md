# 🛒 Grocies Web App

A lightweight and animated grocery checklist app built entirely with HTML, CSS, and JavaScript. Grocies allows users to add, delete, and manage their grocery items in a clean, responsive interface , all with zero backend!

---

## 🎯 Purpose

To create a fully front-end shopping assistant that uses local storage for data persistence. This project demonstrates:

- ✅ Local storage management
- 🎨 Smooth UI/UX with CSS animations
- ⚡ Instant interactions with JavaScript
- 📱 Mobile-first responsive layout

---

## 📋 Features

- ➕ Add new grocery items  
- ✅ Mark items as complete  
- ❌ Delete items instantly  
- 🧠 Remembers your list between sessions using `localStorage`  
- 📱 Optimized for both desktop and mobile devices  
- 🎨 Subtle hover and transition effects for a better user experience  

---

## 🛠️ Tech Stack

- **HTML5** – Structure  
- **CSS3** – Styling, animations  
- **JavaScript** – Functionality and storage handling
